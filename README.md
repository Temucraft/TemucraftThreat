# Temucraft Threat

Threat bars for your group on your target, for WoW 3.3.5a. It uses the game's own threat numbers, so nobody else needs the addon.

- Bars sorted by threat, class colours, threat value and percent of the tank
- The tank is marked
- A raid warning and sound when you reach 90% of pulling (you can change the number)
- Hide out of combat, only in a group, pets on or off, size, scale and opacity

`/tthreat` opens the options. `/tthreat lock`, `/tthreat unlock`, `/tthreat reset`.
